# 🌾 Smart Crop Recommendation & Disease Risk Prediction System

An end-to-end Data Science / Machine Learning portfolio project: a production-style
Streamlit application that recommends the best crop for given soil & climate
conditions, estimates disease risk from weather patterns, suggests fertilizers,
pulls live weather data, and generates downloadable PDF reports — all backed by
trained ML models (RandomForest, LightGBM, XGBoost).

## ✨ Features

| Module | Description |
|---|---|
| 🌱 Crop Recommendation | Top crop + top-5 alternatives with confidence scores, expected yield, PDF report |
| 🦠 Disease Risk Prediction | Weather-driven risk level (Low/Medium/High), prevention & treatment guidance, gauge chart |
| 🧪 Fertilizer Recommendation | Recommended fertilizer, dosage, estimated cost, organic alternative |
| 🌦️ Live Weather | Real-time weather via OpenWeatherMap API |
| 📊 Interactive Dashboard | KPIs, correlation heatmaps, feature importance, prediction stats |
| 📁 Batch Prediction | Upload a CSV, get crop recommendations for every row |
| 📈 Model Performance | RandomForest vs LightGBM vs XGBoost comparison, confusion matrix, ROC-AUC |
| ℹ️ About | Project overview, data sources, tech stack, future scope |

## 📊 Datasets

- **Crop Recommendation** — real Kaggle dataset (`dataset/Crop_recommendation.csv`),
  2,200 rows, 22 balanced crop classes, 7 numeric features, no missing values.
- **Disease Risk** (`disease_risk.csv`), **Fertilizer Recommendation**
  (`fertilizer_recommendation.csv`), **Irrigation** (`irrigation.csv`), and
  **Farmer Records** (`farmer_records.csv`) are realistic **synthetic** datasets
  (5,000+ rows each, balanced classes, no missing values) generated by
  `utils/generate_datasets.py` using domain-informed statistical relationships
  (e.g. higher humidity + leaf wetness → higher fungal disease risk).

> Synthetic data is clearly labelled as such throughout the app and is intended
> for ML demonstration purposes — always validate real-world decisions with a
> local agricultural expert.

## 🖥️ Installation & Running Locally

### 1. Clone / extract the project
```bash
cd Smart-Crop-System
```

### 2. Create a virtual environment
```bash
python3 -m venv venv

# Activate it:
source venv/bin/activate        # macOS / Linux
venv\Scripts\activate           # Windows
```

### 3. Install dependencies
```bash
pip install -r requirements.txt
```

### 4. (Optional) Configure the Weather API
```bash
cp .streamlit/secrets.toml.example .streamlit/secrets.toml
# then edit .streamlit/secrets.toml and paste your OpenWeatherMap API key
# get a free key at https://openweathermap.org/api
```
The app runs fully without a key — the Live Weather page will simply prompt
you to add one, and every other page accepts manual weather input.

### 5. Run the app
```bash
streamlit run app.py
```
Open the URL Streamlit prints (usually `http://localhost:8501`).

## 🧠 Training Models

Trained models are already included in `models/`, so this step is **optional**
(only needed if you change the datasets or want to retrain from scratch).

```bash
# 1. Regenerate synthetic datasets (optional — already included)
python utils/generate_datasets.py

# 2. Train / retrain all models
python utils/train_models.py
```
This writes `.pkl` model + encoder files to `models/` and a metrics summary to
`reports/model_metrics.json`, which powers the **Model Performance** page.

Exploratory notebooks mirroring these steps are in `notebooks/`.

## ☁️ Deployment

### GitHub
```bash
git init
git add .
git commit -m "Initial commit: Smart Crop Recommendation System"
git branch -M main
git remote add origin <your-repo-url>
git push -u origin main
```
`.gitignore` already excludes `.streamlit/secrets.toml`, virtual environments,
and caches — safe to push as-is.

### Streamlit Community Cloud
1. Push the repo to GitHub (above).
2. Go to [share.streamlit.io](https://share.streamlit.io) → **New app**.
3. Select your repo, branch `main`, and main file path `app.py`.
4. Under **Advanced settings → Secrets**, paste:
   ```toml
   OPENWEATHER_API_KEY = "your_key_here"
   ```
5. Click **Deploy**. Streamlit Cloud installs `requirements.txt` automatically.

### VS Code
Open the extracted `Smart-Crop-System/` folder directly in VS Code — the
project needs no extra configuration beyond the virtual environment above.
